Career Copiolit 🚀

Career Copiolit is a frontend-based career guidance platform designed to help students and individuals who are confused about their career choices. It helps users understand their strengths, explore suitable career options, identify the skills they need to develop, and create a personalized career roadmap.

The project combines interactive career assessment, career comparison, roadmap planning, progress tracking, and an AI assistant into one platform.

🌟 Features
🎯 Career Recommendation

Users can explore career options based on their skills, interests, and strengths.

The platform helps users understand which career paths align with their current abilities and provides information to help them make a more informed career decision.

🔍 Explore Careers

Browse different career paths and learn more about:

Career roles
Required skills
Career descriptions
Skills that need to be developed
Possible career directions
⚖️ Career Comparison

Users can compare different career options and understand how they match their skills.

The comparison feature helps users identify suitable career paths before deciding which direction they want to pursue.

🗺️ Personalized Career Roadmap

After exploring their career options, users can create their own roadmap.

The roadmap helps break a larger career goal into smaller steps and allows users to track their progress as they develop the required skills.

📋 Task & Progress Tracking

Users can manage their career-related tasks and monitor their progress.

The dashboard provides an overview of:

Today's tasks
Career progress
Completed tasks
Skills
Saved careers
Learning progress
🤖 Alden — AI Career Assistant

Alden is the AI assistant built into Career Copiolit.

Users can chat with Alden for help with:

Career growth
Career-related questions
Resume building
Skill development
Career roadblocks
General guidance during their career journey

Alden acts as a conversational companion that users can turn to when they need additional guidance.

💾 Local Storage

The project uses browser Local Storage to maintain user-related information and application state without requiring a traditional backend database.

This allows the application to maintain things such as:

User information
Login state
Selected career
Career tasks
Roadmap progress
Other application preferences

💡 Why Career Copiolit?

Choosing a career can be difficult when there are hundreds of possible paths and users may not know which skills they need.

Career Copiolit aims to make the process more structured:

Discover → Compare → Plan → Learn → Track → Grow

Instead of simply suggesting a career, the platform helps users understand what they can do next to move toward their chosen career.

🔐 Data & Privacy

Career Copiolit is primarily a frontend application and uses browser Local Storage for client-side data persistence.

No traditional backend database is required for the core application.

Note: If the AI Assistant uses an external API such as the Gemini API, API credentials should not be exposed directly in frontend code in a production deployment. A secure backend or serverless API layer should be used for production.

2. Open the project
cd career-copiolit
3. Run the project

Open the project in VS Code.
Install the Live Server extension.
Right-click index.html.
Select Open with Live Server.
The website will open in your browser.
🤖 AI Assistant Setup

The AI Assistant uses the Gemini API.

If you are using an API key during development, configure it according to your implementation.

Do not commit private API keys to GitHub.

For a production application, API requests should be handled through a secure backend/serverless function rather than exposing the API key in client-side JavaScript.
